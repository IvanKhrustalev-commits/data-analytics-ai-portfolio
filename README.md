# data-analytics-ai-portfolio
E-Commerce Customer &amp; Sales Analytics: From SQL to AI-Powered Business Insights

I created this portfolio to showcase my ability to think critically, apply technical skills, and use data to solve business problems. 
For this project, I selected the __Brazilian E-commerce Public Dataset by Olist__, which contains information of 100k orders across multiple marketplaces in Brazil. 
[Kaggle Dataset — Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

I will use __Excel, SQL, Python, Tableau, and AI__ to explore the data, identify meaningful patterns, develop business insights, and provide actionable recommendations.
